Well, I checked the code and it is normal the EA take a very few trades (or take no trades at all). The EA looks for a cross in current TF and higher TF and the same time. It almost nerver happens. You should look X bars back for the last cross a set that value. here is the function I use in my EA : PHP Code void getPreviousCrossHigh () { int backBars = 1000 ; for( x = 0 ; x &lt;= backBars ; x ++) { Higher_FastMaVal = GetMa ( hTF , 3 , 0 , 2 , 0 , 0 + x ); Higher_PrevFastMaVal = GetMa ( hTF , 3 , 0 , 2 , 0 , 1 + x ); Higher_SlowMaVal = GetMa ( hTF , 8 , 0 , 2 , 0 , 0 + x ); Higher_PrevSlowMaVal = GetMa ( hTF , 8 , 0 , 2 , 0 , 1 + x ); if ( Higher_FastMaVal &gt; Higher_SlowMaVal &amp;&amp; Higher_PrevFastMaVal &lt; Higher_PrevSlowMaVal ) { higher_cross = up ; break; } if ( Higher_FastMaVal &lt; Higher_SlowMaVal &amp;&amp; Higher_PrevFastMaVal &gt; Higher_PrevSlowMaVal ) { higher_cross = down ; break; } } } Use that one too Cheers, Lh
