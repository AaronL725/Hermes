I'm starting this thread as I haven't seen an Ichimoku thread directly relating to Renko. For this strategy I'm using a 15 pip box and standard Ichimoku 9, 26, 52. I'm not sure about using other indicators with Ichimoku, my heart tells me to keep it 'pure' but I always seem to end up with additional 'confirmation' indicators. I trade long when a box closes outside the Kumo Cloud, the Tenkan Sen is above the Kijun Sen preferably pointing up and the Chikou above the price of 26 periods back, opposite for short. After trying literally hundreds of 'holy grail' strategies Renko trading combined with Ichimoku has been the first trading strategy that has produced overall consistent profits for me, but I'm always looking for that 'extra edge' to make it better. As with most strategies this looks great when trending but ranges can produce losses and any way of filtering ranges should be explored. Anyone not sure what Ichimoku is please check here. http://www.investopedia.com/articles...6/ichimoku.asp All contributions and trading ideas welcome. Which one to use There are 2 versions: one merged with the great pipdefender trade management system, the other one without it. If you want to use the one with pipdefender, make sure you have all those libraries installed (just google pipdefender, download &amp; install it and you should be good). I think it might add something to the bot, as it enables it to 'protect' pips. If you don't want to get confused, I recommand using the 'without pipdef' EA. What it does What it does: it looks at the ZB-CloudMatrix indicator (so you should have that one), if it's green it takes a long, if it's red a short, and if if becomes grey or the opposite colour again it closes the trade. Settings Some basic settings Tekan, Kijun, Senkou, tp &amp; sl speaks for themselves. If you don't want tp or sl set both values very high. You shouldn't have to bother about MagicNumber. I quickly added a trend check with the RSI, if its &gt; 55 then trend is up, if it's lower then 45 then trend is down. Dunno if it's usefull, you can set it to false if it's rubbish. (yes, i did steal that idea from SteveHopwood, and yes i did steal that smiley from him ) I think it might have some potential (although it backtests quite bad, haven't been playing with the settings yet), up to you guys to give it a test and think of improvements that can be made. Don't use it live by the way, might be full of bugs and stuff
