--- 帖子 #138 ---
Suggest that you look at the syntex of the iCustom call in the MQL4 Reference Manual. You can find the MQL Documentation by doing a web search from your search engine. You will find the iCustom call under "Terchnical Indicators". Each MQL indicator provides 8 index regesters that can be populated in the indicator code. If you open the MT4 "Data Window" and scroll down to the VQ Window, you will see the values in the index registers for VQ. Index registers are numbered 0 through 7. So what you see in the data window as "Value 3" is really index register 2. You want to deduce the meaning of the values in index registers 3 and 4, since these are the registers that you have highlighted in the iCustom calls. If you mouse over to an up-arrow in the VQ window, you will see that a value appears in index register 3. If you mouse over to a down-arrow in the VQ window, you will see that a value appears in register 4. Additionally, you can open the VQ parameter box and pull down the "Colors" tab. You will see that an up arrow is the same color as the color for register 3, and a down-arrow is the same color as the color for register 4. So there you have it. In the EA code that you are looking at, when index register 3 is not equal to the EMPTY_VALUE, you have a VQ up-arrow. When index register 4 != EMPTY_VALUE, you have a VQ down-arrow. Hope this explanation helps.
